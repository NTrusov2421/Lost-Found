# Бюро находок

## О проекте

Веб-система бюро находок, предназначенная для размещения, поиска и просмотра объявлений о найденных и потерянных вещах.

Система позволяет пользователям публиковать объявления, добавлять фотографии и информацию о находке или пропаже, выполнять поиск и просматривать объявления. Также предусмотрена административная часть для управления содержимым системы.

Проект разрабатывается как учебное веб-приложение.

## Краткое описание архитектуры

Предлагаемый вариант — **модульный PHP-монолит с серверной генерацией страниц**. Браузер получает HTML и отправляет HTTP-запросы с формами. PHP-приложение выполняет проверку прав, бизнес-логику и запросы к реляционной БД. Вложения хранятся в файловом хранилище, JSON-кэш остаётся в `storage/cache`. Отдельный backend API и микросервисы не предполагаются.
